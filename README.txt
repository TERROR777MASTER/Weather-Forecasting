SKYCAST — 7 DAY WEATHER FORECAST WEBSITE

Files:
- index.html: page structure
- style.css: layout, colors, responsive design
- script.js: city search, API calls, and rendering weather data

HOW TO RUN:
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. (Recommended) Install the "Live Server" extension.
4. Right-click index.html and choose "Open with Live Server".
5. Make sure you have an internet connection.
6. Search for a city to see its current conditions and 7-day forecast.

API:
- Open-Meteo Geocoding API: converts city names to coordinates.
- Open-Meteo Forecast API: provides current conditions and daily forecast.
- No API key is required for non-commercial use.
- Attribution: https://open-meteo.com/

PROJECT CONCEPTS:
HTML structures the page; CSS styles the responsive dashboard; JavaScript uses fetch()
to request API data, processes JSON, and updates the page dynamically.

NOTE:
Forecasts are estimates from weather models. This is a college demonstration project,
not an emergency or safety-critical weather service.
